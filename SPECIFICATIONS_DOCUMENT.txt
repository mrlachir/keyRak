SPECIFICATIONS DOCUMENT: Intelligent Real Estate Booking Platform
1. Context and Project Objectives
As part of a software engineering internship at KEYRAK, this project aims to design and develop a modern SaaS Marketplace platform dedicated to real estate rentals (villas, apartments, and houses).
The primary objective is to modernize the booking experience by replacing complex manual filters with an Artificial Intelligence-powered semantic search, while offering complete visual immersion through 360° virtual tours.
2. Graphic Charter & Visual Identity
The User Interface (UI) will adopt a "Modern Moroccan" (Marrakesh Theme) identity to combine elegance with local character:
• Color Palette: Dominant tones of Terracotta (clay/sand) for backgrounds, with accents of Majorelle Blue for primary Call-to-Action (CTA) buttons and Olive Green.
• Visual Elements: Use of subtle arched borders for property cards (reminiscent of traditional doorways) and the integration of a faint Zellige (Moroccan tile) geometric pattern in the background at low opacity.
• Typography: Clean, modern sans-serif fonts for interface readability, paired with an elegant serif font for property titles to convey a premium feel.
3. Functional Scope
3.1. Client Area (Public Interface & Authenticated User)
• SSO Authentication: Simplified and secure login via Google OAuth (eliminating complex password management).
• AI Search Engine (Natural Language): A single search bar allowing the user to describe their needs (e.g., "Quiet villa with a pool in Marrakech for 4 people"). The AI parses this sentence into structured filters.
• Search Results Display: A split-screen layout featuring a scrollable list of property cards on the left and an interactive map (Mapbox/Leaflet) with dynamic markers on the right.
• Property Profile:
o Media Viewer: A dynamic header to toggle between standard photo galleries, video players, and a 360° image viewer (equirectangular).
o AI-generated description and a grid of amenities (Tags with icons).
o Read-Only Sidebar Calendar: Displays unavailable (booked) dates in red.
• Booking Tunnel (Modal):
o Triggered by the "Book Now" button.
o Interactive date selection (red days are blocked).
o Detailed form: Number of adults, children, and special requests.
o Real-time total price calculator.
• Client Dashboard: Tracking of past and upcoming trips, along with booking statuses (PENDING, CONFIRMED, CANCELLED).
3.2. Administrator Area (Back-Office Management)
• Dashboard: Overview of Key Performance Indicators (KPIs) such as total active properties, pending booking requests, and revenue.
• Property Management (CRUD): Interface to create, read, update, and delete properties.
• Multimedia Upload: Dropzone interface for uploading standard images, videos, and 360° files.
• AI Copywriting Assistant: One-click generation of highly optimized property descriptions by the AI, based on the amenities selected by the admin.
• Booking Validation: A control table to review incoming requests and manually approve (blocking the dates) or reject reservations.
4. Technical Architecture
The project relies on a decoupled architecture ensuring high performance, SEO optimization, and transactional security.
• Frontend (Client & Admin):
o Framework: Next.js (App Router) with React.
o Styling: Tailwind CSS.
o Authentication: NextAuth.js (Auth.js) with Google Provider.
o State & Fetching: React Server Components and Server Actions.
• Backend (API & Business Logic):
o Framework: Spring Boot (Java).
o Security: Spring Security with JWT token validation (tokens generated by the frontend).
o Artificial Intelligence: Integration of the Gemini API (Google) for semantic search and description generation.
• Database:
o RDBMS: MySQL (Relational architecture ensuring ACID compliance to strictly prevent booking conflicts).
5. Data Modeling (Relational Schema)
The system is structured around 6 core entities:

Table,Description,Primary Key
users,"Users (Client/Admin), synchronized with Google SSO.",id (UUID)
properties,"Main property data (title, price, lat/lng).",id (UUID)
property_media,"URLs of media files. Manages types (IMAGE, VIDEO, 360_IMAGE).",id (UUID)
tags,"Dictionary of amenities (e.g., WiFi, Pool).",id (INT)
property_tags,Junction table (Many-to-Many relationship).,property_id + tag_id
bookings,"Reservations (dates, guest count, price, status).",id (UUID)

6. Deployment & Deliverables
• Deliverable 1: Complete source code (Frontend + Backend) hosted on a private Git repository.
• Deliverable 2: SQL script for database creation (database.sql).
• Deliverable 3: A docker-compose.yml file to launch the entire environment (Application + Database) via a single command.
